# Pure_Documentation_Index

PureBasic Documentation Index generates a searchable standalone HTML index of PureBasic commands and functions, including Syntax, descriptions, Return value.

Source: Local PureBasic IDE OpenSource Repository.<br/>
Target: [GitHub — PureBasic OpenSource](https://github.com/fantaisie-software/purebasic) Documentation/English<br/>

The goal is to share the HTML index or the more compact JSON index (#CreateJSON = #True | #False) with AIs for their chat context, providing a reference for PureBasic syntax, functions, operators, and behaviour to check against whenever in doubt. They have no absolute reference, the documentation is just data in their Training data.
Written in collaboration with Claude<br/>
